## Setup

### Prerequisites

- [Godot](https://godotengine.org)

### Local Development

1. Clone this repo w/ `git clone https://github.com/Paylicier/RickTheGame`
2. Open it in godot
3. Start the game with <kbd>CTRL</kbd> / <kbd>CMD</kbd> + <kbd>B</kbd>
